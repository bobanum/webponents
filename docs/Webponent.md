# Webponent Base Class

> Docs generated by AI. Not revised yet.

The `Webponent` class is the foundation of the Webponents framework. It extends `HTMLElement` to provide a robust system for creating custom web components with reactive properties, automatic attribute synchronization, and type coercion.

## Overview

Webponent provides a declarative way to define custom web components with:

- **Reactive Properties**: Properties that automatically sync with HTML attributes
- **Type Coercion**: Automatic type conversion for common data types
- **Shadow DOM**: Built-in shadow root for style encapsulation
- **Lifecycle Hooks**: Custom behavior during property changes
- **Automatic Registration**: Simple API for registering custom elements

## Class Definition

```javascript
export default class Webponent extends HTMLElement {
  static affix = '-ponent';
  static properties = {};
  // ... methods
}
```

## Static Properties

### `affix`

- **Type**: `string`
- **Default**: `'-ponent'`
- **Description**: Prefix or suffix (or both) added to the component tag name during registration 
**Examples:**
- `'app-'` => prefix 'app-tag'
- `'-ponent'` => suffix 'tag-ponent'
- `'app-ponent'` => both 'app-tag-ponent'

### `properties`

- **Type**: `Object`
- **Default**: `{}`
- **Description**: Object defining reactive properties for the component

**Example:**
```javascript
static properties = {
  count: {
    type: Number,
    default: 0
  },
  disabled: {
    type: Boolean,
    default: false
  }
};
```

### `meta`

- **Type**: `Object | undefined`
- **Description**: Metadata object that can be set via `setMeta()`

## Static Methods

### `register(name)`

Registers the component as a custom HTML element.

**Parameters:**
- `name` (string, optional): Custom element tag name. If not provided, uses the class name converted to kebab-case

**Returns:** `undefined`

**Example:**
```javascript
class MyComponent extends Webponent {}

// Registers as 'my-component-ponent'
MyComponent.register();

// Registers as 'my-widget'
MyComponent.register('my-widget');

// Registers as 'app-component'
MyComponent.register('component', 'app', '');
```

**Behavior:**
- Automatically converts class names to kebab-case
- Checks if element is already registered before registering
- Logs registration to console

### `defineProperties(descriptors)`

Defines reactive properties on the component prototype.

**Parameters:**
- `descriptors` (Object): Object mapping property names to property descriptors

**Returns:** `Array<string>` - Array of property names

**Example:**
```javascript
Webponent.defineProperties({
  value: {
    type: String,
    default: ''
  },
  max: {
    type: Number,
    default: 100
  }
});
```

### `defineProperty(name, prop)`

Defines a single reactive property on the component prototype.

**Parameters:**
- `name` (string): Property name
- `prop` (Object | Function | any): Property descriptor, type constructor, or default value

**Returns:** `undefined`

**Descriptor Options:**
- `type` (Function): Type constructor (String, Number, Boolean, etc.)
- `default` (any): Default value
- `assert` (Function): Custom validation/coercion function
- `get` (Function): Custom getter
- `set` (Function): Custom setter (called after value changes)

**Example:**
```javascript
// Using full descriptor
Webponent.defineProperty('count', {
  type: Number,
  default: 0,
  assert(value) {
    return Math.max(0, value); // Ensure non-negative
  },
  set(value) {
    console.log(`Count changed to ${value}`);
  }
});

// Using just a type
Webponent.defineProperty('name', String);

// Using a default value
Webponent.defineProperty('active', true);
```

### `setMeta(meta)`

Sets metadata for the component and extracts URL parameters.

**Parameters:**
- `meta` (Object): Metadata object with a `url` property

**Returns:** `this` (for chaining)

**Example:**
```javascript
MyComponent.setMeta({
  url: 'https://example.com?foo=bar&baz=qux'
});
// Sets MyComponent.foo = 'bar' and MyComponent.baz = 'qux'
```

### `fixed(name)`

Generates the final custom element tag name with prefix and suffix.

**Parameters:**
- `name` (string): Base name

**Returns:** `string` - The formatted tag name

**Example:**
```javascript
Webponent.fixed('MyComponent', 'app', 'widget');
// Returns: 'app-my-component-widget'
```

### `toKebabCase(name)`

Converts a camelCase or PascalCase string to kebab-case.

**Parameters:**
- `name` (string): String to convert

**Returns:** `string` - Kebab-case string

**Example:**
```javascript
Webponent.toKebabCase('MyComponent');      // 'my-component'
Webponent.toKebabCase('customButton');     // 'custom-button'
Webponent.toKebabCase('HTML5Element');     // 'h-t-m-l5-element'
```

### `getUrlData(url, obj)`

Extracts query parameters from a URL and assigns them to an object.

**Parameters:**
- `url` (string): URL with query parameters
- `obj` (Object): Target object (defaults to the class itself)

**Returns:** `Object` - The target object

**Example:**
```javascript
const data = {};
Webponent.getUrlData('https://api.com?page=1&limit=10', data);
// data = { page: '1', limit: '10' }
```

### `get observedAttributes()`

Returns an array of attribute names that should be observed for changes.

**Returns:** `Array<string>` - Property names from `static properties`

**Note:** This is automatically called by the browser when the component is registered.

## Static Properties - Type Assertions

### `asserts`

Object containing built-in type assertion functions.

**Built-in Assertions:**

#### `Number`
Converts value to a number, returns `undefined` if NaN.
```javascript
asserts.Number('42');      // 42
asserts.Number('abc');     // undefined
asserts.Number(new Number(5)); // 5
```

#### `Boolean`
Converts value to boolean, handles 'false' string specially.
```javascript
asserts.Boolean('false');  // false
asserts.Boolean('true');   // true
asserts.Boolean('');       // true (non-empty string)
asserts.Boolean(0);        // false
```

#### `Integer`
Converts value to an integer using `parseInt`.
```javascript
asserts.Integer('42.7');   // 42
asserts.Integer(42.7);     // 42
asserts.Integer('abc');    // undefined
```

#### `Float`
Converts value to a float using `parseFloat`.
```javascript
asserts.Float('42.7');     // 42.7
asserts.Float('42');       // 42
asserts.Float('abc');      // undefined
```

## Instance Properties

### `_`

- **Type**: `Proxy`
- **Description**: Internal storage for property values, wrapped in a proxy for automatic attribute synchronization

### `_$`

- **Type**: `Object`
- **Description**: Internal storage object (currently unused in the base implementation)

### `shadowRoot`

- **Type**: `ShadowRoot`
- **Description**: The component's shadow DOM root, created with `mode: 'open'`

## Instance Methods

### `constructor()`

Initializes the component instance.

**Behavior:**
- Calls `super()` to initialize HTMLElement
- Creates the internal proxy via `createProxy()`
- Initializes `_$` storage object
- Attaches a shadow root in open mode

### `createProxy(obj)`

Creates a proxy for automatic attribute-property synchronization.

**Parameters:**
- `obj` (Object): Initial object to wrap (default: `{}`)

**Returns:** `Proxy` - Proxied object

**Behavior:**
- **Get trap**: Returns value from the proxy target
- **Set trap**: 
  - Updates the proxy target
  - Synchronizes with HTML attributes
  - Removes attribute if value is null, undefined, or false
  - Sets attribute to empty string if value is true
  - Otherwise sets attribute to the string value

**Example:**
```javascript
// When you do:
this._.disabled = true;
// The proxy automatically does:
this.setAttribute('disabled', '');

// When you do:
this._.value = null;
// The proxy automatically does:
this.removeAttribute('value');
```

### `attributeChangedCallback(name, oldValue, newValue)`

Lifecycle hook called when an observed attribute changes.

**Parameters:**
- `name` (string): Attribute name
- `oldValue` (string): Previous attribute value
- `newValue` (string): New attribute value

**Behavior:**
- Ignores changes where old and new values are the same
- Sets the corresponding property to the new attribute value
- Triggers property setters which may invoke custom logic

**Example:**
```html
<my-component count="5"></my-component>
<script>
  // Changing the attribute triggers the callback
  element.setAttribute('count', '10');
  // This calls: attributeChangedCallback('count', '5', '10')
  // Which sets: this.count = '10'
  // Which is converted to: this.count = 10 (via Number assertion)
</script>
```

## Property System

### How Properties Work

1. **Definition**: Properties are defined in the static `properties` object
2. **Registration**: During class initialization, properties are defined on the prototype
3. **Observation**: Property names are added to `observedAttributes`
4. **Type Coercion**: Values are passed through assertion functions
5. **Synchronization**: Changes sync between properties and attributes
6. **Lifecycle Hooks**: Custom getters and setters provide fine-grained control

### Property Flow

```
HTML Attribute → attributeChangedCallback → Property Setter → Assert Function → Store in _ → Custom Set Hook
     ↑                                                                                            ↓
     └────────────────────────────────── Proxy Set Trap ← Property Assignment ──────────────────┘
```

### Property Descriptor Structure

```javascript
{
  type: Function,           // Type constructor for coercion
  default: any,             // Default value
  assert: Function,         // Custom validation/coercion
  get: Function,            // Custom getter
  set: Function             // Custom setter (post-change hook)
}
```

### Shorthand Syntaxes

```javascript
// Full descriptor
level: {
  type: Number,
  default: 1,
  assert(value) { return Math.max(1, Math.min(6, value)); },
  set(value) { this.render(); }
}

// Just a type
name: { type: String }

// Just a type (shorthand)
name: String

// Type with default
count: {
  type: Number,
  default: 0
}

// Default value (type inferred from constructor)
active: true  // Becomes: { type: Boolean, default: true }
```

## Type Assertions

Type assertions are functions that validate and coerce property values.

### Built-in Assertions

The `asserts` object provides pre-built assertions for common types:
- `Number`: Numeric values
- `Boolean`: Boolean values (handles 'false' string)
- `Integer`: Whole numbers
- `Float`: Floating-point numbers

### Custom Assertions

You can define custom assertion logic:

```javascript
static properties = {
  email: {
    type: String,
    assert(value) {
      // Validate email format
      if (!/^[^\s@]+@[^\s@]+\.[^\s@]+$/.test(value)) {
        console.warn('Invalid email:', value);
        return undefined; // Reject invalid values
      }
      return value.toLowerCase(); // Normalize to lowercase
    }
  },
  
  percentage: {
    type: Number,
    assert(value) {
      value = Number(value);
      if (isNaN(value)) return 0;
      return Math.max(0, Math.min(100, value)); // Clamp to 0-100
    }
  },
  
  status: {
    type: String,
    assert(value) {
      const valid = ['pending', 'active', 'completed'];
      return valid.includes(value) ? value : 'pending';
    }
  }
};
```

## Examples

### Basic Component

```javascript
import Webponent from './Webponent.js';

class SimpleButton extends Webponent {
  connectedCallback() {
    this.shadowRoot.innerHTML = `
      <style>
        button {
          background: var(--button-bg, blue);
          color: white;
          padding: 10px 20px;
          border: none;
          border-radius: 4px;
        }
        button:disabled {
          opacity: 0.5;
          cursor: not-allowed;
        }
      </style>
      <button>
        <slot></slot>
      </button>
    `;
    
    const button = this.shadowRoot.querySelector('button');
    button.disabled = this.disabled;
  }
  
  static properties = {
    disabled: Boolean
  };
}

SimpleButton.register('simple-button', '', '');
```

```html
<simple-button>Click Me</simple-button>
<simple-button disabled>Disabled</simple-button>
```

### Component with Rendering

```javascript
class ProgressBar extends Webponent {
  connectedCallback() {
    this.render();
  }
  
  render() {
    this.shadowRoot.innerHTML = `
      <style>
        .progress {
          width: 100%;
          height: 20px;
          background: #eee;
          border-radius: 10px;
          overflow: hidden;
        }
        .bar {
          height: 100%;
          background: #4caf50;
          transition: width 0.3s;
        }
      </style>
      <div class="progress">
        <div class="bar" style="width: ${this.value}%"></div>
      </div>
      <div>${this.value}%</div>
    `;
  }
  
  static properties = {
    value: {
      type: Number,
      default: 0,
      assert(value) {
        return Math.max(0, Math.min(100, value));
      },
      set() {
        this.render();
      }
    }
  };
}

ProgressBar.register();
```

```html
<progress-bar-ponent value="75"></progress-bar-ponent>
```

### Component with Complex Properties

```javascript
class UserCard extends Webponent {
  connectedCallback() {
    this.render();
  }
  
  render() {
    this.shadowRoot.innerHTML = `
      <style>
        .card {
          border: 1px solid #ddd;
          padding: 16px;
          border-radius: 8px;
        }
        .avatar {
          width: 64px;
          height: 64px;
          border-radius: 50%;
          background: #ccc;
        }
        .name { font-weight: bold; }
        .email { color: #666; }
      </style>
      <div class="card">
        ${this.avatar ? `<img class="avatar" src="${this.avatar}">` : '<div class="avatar"></div>'}
        <div class="name">${this.name}</div>
        <div class="email">${this.email}</div>
        ${this.verified ? '<div>✓ Verified</div>' : ''}
      </div>
    `;
  }
  
  static properties = {
    name: {
      type: String,
      default: 'Anonymous',
      set() { this.render(); }
    },
    email: {
      type: String,
      default: '',
      assert(value) {
        return value.toLowerCase();
      },
      set() { this.render(); }
    },
    avatar: {
      type: String,
      default: '',
      set() { this.render(); }
    },
    verified: {
      type: Boolean,
      default: false,
      set() { this.render(); }
    }
  };
}

UserCard.register();
```

```html
<user-card-ponent 
  name="John Doe" 
  email="john@example.com"
  avatar="https://example.com/avatar.jpg"
  verified>
</user-card-ponent>
```

## Best Practices

1. **Always call `super()` first** in your constructor if you override it
2. **Use `connectedCallback()`** for initialization that requires DOM access
3. **Define properties statically** to enable attribute observation
4. **Provide default values** for all properties
5. **Use type assertions** to ensure data integrity
6. **Leverage the `set` hook** for reactive rendering
7. **Use shadow DOM** for style encapsulation
8. **Keep components focused** - single responsibility principle
9. **Document your properties** and their expected values
10. **Test edge cases** in your assertion functions

## Common Patterns

### Reactive Rendering Pattern

```javascript
static properties = {
  data: {
    type: String,
    set() { this.render(); }
  }
};

render() {
  this.shadowRoot.innerHTML = `...${this.data}...`;
}
```

### Validation Pattern

```javascript
static properties = {
  value: {
    type: Number,
    assert(value) {
      if (!this.isValid(value)) {
        console.warn('Invalid value:', value);
        return this.value; // Keep previous value
      }
      return value;
    }
  }
};
```

### Computed Properties Pattern

```javascript
static properties = {
  firstName: String,
  lastName: String,
  fullName: {
    get() {
      return `${this.firstName} ${this.lastName}`;
    }
  }
};
```
